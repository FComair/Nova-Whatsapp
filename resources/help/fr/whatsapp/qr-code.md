Le QR code est réservé au **propriétaire** : **Réglages > QR code WhatsApp**.

## Comment ça marche

1. Créez un QR code. Un client le scanne avec son téléphone : WhatsApp s’ouvre sur une conversation avec votre numéro.
2. Il écrit, et l’assistant de Nova l’aide à réserver.
3. Téléchargez le QR code pour l’imprimer sur une affiche, un comptoir, une carte de visite ou une vitrine.

## Suivre ce que ça rapporte

Les clients arrivés par ce moyen sont enregistrés avec la provenance **QR code WhatsApp** : vous pouvez les retrouver avec le filtre **Provenance** de la liste **Clients**.

> **Prérequis :** votre numéro WhatsApp doit être connecté (voir « Connecter votre numéro WhatsApp »).
