## Mot de passe oublié

Sur la page de connexion, utilisez **Mot de passe oublié** : Rendivoo envoie un lien de réinitialisation à votre adresse e-mail. Choisissez un mot de passe d’au moins 12 caractères.

## Le code de la double authentification est refusé

- Vérifiez que l’**heure de votre téléphone** est réglée automatiquement : un décalage de quelques minutes suffit à invalider le code.
- Attendez le prochain code de l’application et saisissez-le sans espace.
- Si vous avez perdu votre téléphone, utilisez un **code de secours** (chacun ne sert qu’une fois).

## Trop de tentatives

Après plusieurs codes incorrects, la connexion est bloquée quelques minutes. Attendez, puis réessayez sans multiplier les essais.

## Adresse e-mail non vérifiée

Ouvrez l’e-mail de confirmation reçu à l’inscription, ou demandez un nouvel envoi depuis la page de vérification.
