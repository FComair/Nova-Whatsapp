Tout se fait dans **Réglages > Sécurité**. Pour chaque changement, Rendivoo demande votre **mot de passe actuel**.

## Mot de passe

12 caractères minimum, avec une majuscule, une minuscule, un chiffre et un caractère spécial. Les 5 derniers mots de passe ne peuvent pas être réutilisés. Changer de mot de passe ferme vos autres sessions.

## Adresse e-mail

Saisissez la nouvelle adresse : Rendivoo envoie un lien de confirmation à cette adresse et prévient l’ancienne. Le changement n’a lieu qu’après confirmation.

## Téléphone professionnel

Saisissez le nouveau numéro avec son indicatif (+32…). Un code est envoyé à ce **nouveau** numéro ; l’ancien reste actif tant que le code n’est pas confirmé.

## Sessions

Vous pouvez fermer vos autres sessions si vous pensez qu’un appareil n’est plus sûr.
