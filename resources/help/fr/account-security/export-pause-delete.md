Ces actions sont dans **Réglages > Mes données** et réservées au **propriétaire**.

## Exporter vos données

Téléchargez une copie des données de votre établissement : clients, rendez-vous, services, équipe. Utile pour vos archives ou une demande de portabilité.

## Mettre en pause

La pause suspend l’établissement temporairement (vacances, fermeture). Les rendez-vous concernés sont annulés et les clients prévenus ; vous pouvez reprendre ensuite.

## Supprimer le compte

La suppression demande une **confirmation en deux étapes**. Les données de l’établissement sont ensuite effacées, sauf ce que la loi impose de conserver (factures). Pensez à **exporter vos données avant**.

> **Vous voulez seulement effacer un client ?** Voir « Effacer les données d’un client ».
