The number identifies the customer in WhatsApp, and its country code matters: a 06 is a mobile number in France and in the Netherlands alike.

## The rule

- **With a country code** (+32 470 12 34 56, +31 6 12345678 or 0032…): the number is saved as typed, whatever your business’s country.
- **Without a country code** (0470 12 34 56): Nova reads it in **your business’s country**. A number that does not exist in that country is refused rather than attached to another country.
- If your country is not known and the number could belong to several countries, Nova asks you to add the country code.

## Advice

For a foreign customer or any doubt, always type the full code with the **+**.

## A customer saved with the wrong country code

The number on an existing profile cannot be edited, because it identifies the customer. If a customer was saved with the wrong country, contact support to correct it.
